# Homebrew Tap

Homebrew packages by [@marcomontalbano](https://github.com/marcomontalbano). All packages require macOS.

## Packages

### [siri-say](https://marcomontalbano.com/project/siri-say/)

Speak text with any macOS voice, including the Siri voices.

[![siri-say](https://raw.githubusercontent.com/marcomontalbano/siri-say/main/cover.png)](https://marcomontalbano.com/project/siri-say/)

```sh
brew install marcomontalbano/tap/siri-say
```

### [tailserve](https://marcomontalbano.com/project/tailserve/)

Serve your dev servers on your tailnet, automatically.

[![tailserve](https://raw.githubusercontent.com/marcomontalbano/tailserve/main/cover.png)](https://marcomontalbano.com/project/tailserve/)

```sh
brew install marcomontalbano/tap/tailserve
```

Installing with the full name, as above, taps this repository and trusts only the package you install.

## Using the tap

To install by short name (`brew install siri-say`), tap the repository and trust the packages you want:

```sh
brew tap marcomontalbano/tap
brew trust --formula marcomontalbano/tap/siri-say
brew trust --cask marcomontalbano/tap/tailserve
```

In a `Brewfile`:

```ruby
brew "marcomontalbano/tap/siri-say", trusted: true
cask "marcomontalbano/tap/tailserve", trusted: true
```

## Maintaining

Each package is updated by its upstream release, so a new version needs no change here.

- `Casks/tailserve.rb` is regenerated by GoReleaser on every tailserve release. Change the GoReleaser configuration in tailserve instead of editing the cask here.
- `Formula/siri-say.rb` gets its `url` and `sha256` lines rewritten by the siri-say release workflow; everything else is maintained here. Keep those two lines in their `  url "…"` / `  sha256 "…"` form, or the workflow stops matching them.
